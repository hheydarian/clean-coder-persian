## 💡 چرا این پروژه؟

کتاب **The Clean Coder: A Code of Conduct for Professional Programmers** نوشته‌ی *رابرت سی. مارتین (Robert C. Martin / عمو باب)*، فراتر از نحوه‌ی نوشتن کد است و به «حرفه‌ای بودن» در مهندسی نرم‌افزار می‌پردازد: از زمان نه گفتن و بله گفتنِ مسئولانه تا تخمین‌زدن، TDD و کار تیمی.

هدف ما در این پروژه اوپن‌سورس:
* 🎯 **ترجمه‌ای روان، دقیق و وفادار** به تجربه‌های عملی و اخلاق مهندسی نرم‌افزار
* 💻 **همکاری مشترک و آزاد جامعه** حاصل تلاش [حامد حیدریان](https://github.com/hheydarian) و [مهدی محسنی](https://github.com/wukalt)
* 🌍 **ارتقای استاندارد حرفه‌ای** در تیم‌های نرم‌افزاری و تقویت دانش دوزبانه برنامه‌نویسان

## 🤝 مشارکت در پروژه (Contributions Welcome)

این یک پروژه اجتماعی متعلق به تمام توسعه‌دهندگان و علاقه‌مندان است. هر تصحیح نگارشی، بهبود در واژه‌گزینی‌های تخصصی یا بهینه‌سازی ساختار متن، ارزش این منبع را دوچندان می‌کند:

1. **فورک کنید (Fork):** ریپازیتوری را فورک کرده و یک برنچ جدید بسازید (`git checkout -b feature/edit-chapter-01`).
2. **اصلاح و بازبینی:** متن یا بخش‌های مورد نظر را اصلاح کنید.
3. **کامیت و ارسال:** تغییرات را ثبت کرده و یک Pull Request تمیز ارسال فرمایید.

> اگر سوال، ابهام یا پیشنهادی درباره مطالب یا ترجمه دارید، خوشحال می‌شویم آن را از طریق بخش **[Issues](https://github.com/hheydarian/clean-coder-persian/issues)** مطرح کنید.
